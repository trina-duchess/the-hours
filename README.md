# The Hours

A personal time-budget app: a weekly plan, month view, year view, events, routines, tasks and life goals.

Live site: https://trina-duchess.github.io/the-hours/

## Files
- `index.html` — the whole app (one file).
- `icon-180.png` — home-screen icon.

## Your data
Everything is saved in the browser you use, on that device. It isn't stored in this repo.
Use **Year → Your data → Export backup (JSON)** now and then, and **Import file** to move your data to another device.

## Updating
Replace `index.html` with the new version and commit. GitHub Pages republishes in a minute or two.
